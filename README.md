## Klasör yapısı

```
automotive-electrical-fault-lab/
├── README.md
├── notes/     # Arıza senaryoları, ölçüm notları ve teşhis adımları
├── falstad/   # Falstad devre simülatörü dosyaları
├── tools/     # Yardımcı betikler ve araçlar
└── tests/     # Araçlar ve senaryolar için testler
```
